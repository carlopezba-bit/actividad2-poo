# Actividad 2 - Programación Orientada a Objetos

Actividad correspondiente al curso de Programación Orientada a Objetos.

Los ejercicios fueron desarrollados en Python a partir de los ejercicios
propuestos en el libro *Ejercicios de programación orientada a objetos
con Java y UML* de Leonardo Bermón Angarita.

## Lenguaje utilizado

Python

## Ejercicios desarrollados

### Ejercicio 2.1 - Persona
Implementación de una clase Persona con atributos personales,
constructor y método para imprimir la información.

### Ejercicio 2.2 - Planeta
Implementación de una clase Planeta con diferentes atributos,
tipos enumerados y métodos para calcular la densidad y determinar
si un planeta es exterior.

### Ejercicio 2.3 - Automóvil
Implementación de una clase Automovil con métodos get y set,
aceleración, desaceleración, frenado y cálculo del tiempo de llegada.

### Ejercicio 2.4 - Figuras geométricas
Implementación de las clases Circulo, Rectangulo, Cuadrado y
TrianguloRectangulo, con métodos para calcular áreas y perímetros.

### Ejercicio 2.5 - Cuenta bancaria
Implementación de una clase CuentaBancaria que permite consultar
saldo, consignar y retirar dinero.

## Contenido del repositorio

- Código fuente de los ejercicios en Python.
